# Prism documentation site

The documentation site is built with Docusaurus 3. From this directory:

```bash
npm ci
npm start
```

Create the production build with `npm run build`. The documentation source is
in [`docs`](docs), and the runnable quick-start program is in
[`static/examples/quick-start`](static/examples/quick-start).
